# Evaluation Outputs & Artifacts

This directory stores evaluation metrics, quantitative validation reports, diagnostic plots, and visual explainability artifacts generated by the system.

---

## Subdirectory Structure

- **`reports/`**:
  - `evaluation_metrics.json`: Quantitative summary of performance metrics (AUROC, Sensitivity/Recall, Specificity, Accuracy, F1-Score).
  - `classification_report.txt`: Class-wise precision, recall, and support.
- **`plots/`**:
  - `confusion_matrix.png`: Normalized and raw confusion matrix visualization.
  - `roc_curve.png`: Receiver Operating Characteristic (ROC) curve showing True Positive Rate vs False Positive Rate.
  - `gradcam_overlay_*.png`: Class activation maps overlaying model focus on sample test radiographs.
