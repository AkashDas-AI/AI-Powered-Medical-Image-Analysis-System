## Usage Notice

All radiograph assets in this directory originate from the de-identified RSNA 2018 Pneumonia Detection Challenge adjudicated cohort. No protected health information (PHI) is present. These visual assets serve as reproducible evidence of model training, evaluation, and explainability execution for educational and portfolio presentation.
