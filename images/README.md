# Visual Assets & System Diagrams

This directory stores visual assets used in project documentation, architecture diagrams, and educational presentations.

---

## Intended Contents

- Architectural schematic diagrams (`architecture_diagram.png`).
- High-level data processing flowcharts.
- Example interface wireframes and report mockups.
- Documentation badges and visual banners.

> [!NOTE]
> Do NOT store full clinical datasets or raw patient medical images in this directory.
